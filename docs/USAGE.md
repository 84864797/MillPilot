# 操作指南

## 主界面

- 左侧显示 INI 指定的坐标轴、回零指示、当前刀具；“置零”修改对应工件坐标，不是机床回零。
- 右侧页面依次为刀路预览、程序列表、工件坐标、刀具表、MDI、设置。
- 底部包含程序控制、主轴控制、倍率和点动；最下方为状态、可选启动代码与时钟。

## 主轴

按钮从左到右为 **反转 / 停止 / 正转**。设定转速后点方向按钮启动。主轴运行时点“应用”更新转速并保持当前方向；停止时点“应用”不会启动主轴，随后启动会读取输入框当前值。

按钮按住时变亮，控制器报告运行后对应方向保持青色高亮。停止后“停止”高亮。电源未开、急停或程序尚未停止时，不允许手动启动。程序在 AUTO 模式但已经停止时，点击方向按钮会切换到手动模式。

高亮反映 LinuxCNC 控制状态，不证明主轴电机已经转动；实际转速和负载依赖独立硬件反馈。

## 全部回零

按 INI 的 `HOME_SEQUENCE` 执行全部关节回零。回零中显示“回零中…”，禁止重复触发。完成后按钮高亮。再次点击是重新回零，不是取消回零。需要中止时用停止或 Esc。

## 工件坐标与刀具

点击可编辑的数值单元格打开深色计算器，输入后按 Apply 确认，Cancel 取消。修改刀具说明使用文字键盘。刀具新增、勾选删除、重新载入使用表格上方按钮；删除有确认提示。

## 设置页

| 入口 | 用途 |
| --- | --- |
| 梯形图 | 打开已加载的 ClassicLadder；未加载组件时给出说明 |
| HAL 示波器 | 用 halscope 观察 HAL 波形 |
| 状态 | 用 linuxcnctop 查看控制器状态 |
| HAL 仪表 | 用 halmeter 观察单个 HAL 值 |
| 调校 | 打开 LinuxCNC 的 Calibration 工具 |
| HAL 配置 | 用 HAL Show 查看引脚、信号与参数 |

工具使用本机 LinuxCNC 程序，在独立窗口打开，其外观由系统决定。调试工具能够影响机床，使用前应理解对应参数和机床接线。

“界面选项”中可关闭键盘点动、显示/隐藏刀路坐标叠加、切换全屏、恢复 3D 视角。键盘点动和叠加显示写入机床目录的 `cnc_3axis_1024.pref`。全屏通过 F11 也可切换。机床信息页只读显示配置摘要。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| F1 | 急停切换 |
| F2 | 设备电源切换 |
| Home | 全部回零，与屏幕按钮使用相同检查 |
| Esc | 停止 / 中止 |
| F11 | 全屏切换 |
| 方向键 | X / Y 点动（启用键盘点动后） |
| PageUp / PageDown | Z 点动 |
| Shift + 点动键 | 加速点动；使用前确认机器速度范围 |

在 MDI、程序编辑器、数值输入和对话框中输入时，普通输入键交给编辑器处理；急停/停止快捷键仍有效。关闭键盘点动不影响屏幕点动和急停/停止快捷键。
